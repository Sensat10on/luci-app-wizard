# Перенос проекта на другой ПК

Распакуйте архив и откройте папку `luci-app-wizard` в Codex или любом редакторе.

Внутри есть исходники, Git-история и готовый APK для OpenWrt 25.12 `ramips/mt7621`. Приватные ключи SSH и любые пароли намеренно не включены.

Для продолжения работы с GitHub выполните вход в GitHub CLI на новом ПК. Удалённый репозиторий уже настроен как `origin`:

```sh
git status
git pull
```

Готовый пакет находится в папке `release`. Для установки на совместимый роутер передайте APK в `/tmp` и выполните:

```sh
apk add --allow-untrusted /tmp/luci-app-wizard_0.1.0-r1_mipsel_24kc.apk
```

Сборка нового APK выполняется GitHub Actions после отправки изменений в ветку `main` либо вручную на странице Actions.
